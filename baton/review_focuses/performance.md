# Performance review

Inspect redundant database round trips, inefficient queries, unnecessary network
calls and avoidable repeated work. Flag load-sensitive startup, lifecycle,
concurrency, retry/queueing and cleanup paths, including failures or cancellation.
Explain concrete resource or latency costs with evidence in the changed code.
Identify representative-load validation needed to test the risk; this diff-based
review does not supply measured runtime acceptance or invent project budgets.
